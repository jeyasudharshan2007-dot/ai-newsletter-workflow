CAPSTONE 51 — AI Newsletter Production Workflow

Project Question

Can AI help produce a weekly newsletter reliably?

Project Overview

This project explores how artificial intelligence can support the production of a weekly newsletter through research, content writing, fact-checking, design, and automation.

Objectives

- Collect relevant news from reliable sources.
- Use AI to summarize articles and draft newsletter content.
- Verify facts, publication dates, and source links.
- Design a professional newsletter layout.
- Automate repetitive content collection tasks.
- Publish a complete sample newsletter.

Tools Used

- ChatGPT — content generation and editing
- Perplexity — research and source discovery
- Canva — newsletter design
- Google Docs — documentation
- Zapier — workflow automation

Project Structure

- "research/" — source list and verification report
- "prompts/" — reusable AI prompts
- "newsletters/" — drafts and sample issue
- "design/" — newsletter layout and design assets
- "automation/" — automation workflow documentation
- "evaluation/" — before/after analysis
- "demo/" — final presentation and evidence

Reliability Measures

All newsletter claims will be checked against original sources. Links, dates, and important facts will be verified before publication.

Project Status

In progress.
